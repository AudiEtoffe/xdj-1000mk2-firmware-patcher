What this does

Turns Pioneer’s original XDJ-1000MK2 1.45 update file into firmware 2.0, right here in your browser:
  • exFAT USB drives — the player reads exFAT sticks and drives (including 64 GB and larger) as well as FAT32. Edits that keep a file’s size (such as saved hot cues) are written back to the stick; anything that needs a new or larger file is not saved yet.
  • Extra features (optional) — 3-band waveform colours, 32-beat loops, gated hot cues, extended beat jump.
  • 88.2 / 96 kHz FLAC and WAV HAS NOT BEEN TESTED (optional, experimental) — as on the CDJ-2000NXS2.

Your file never leaves your computer: nothing is uploaded, and nothing of Pioneer’s is stored on this site.

Download the XDJ-1000MK2 1.45 firmware from Pioneer DJ’s support site, unzip it, and pick the file XDJ1KMK2.UPD.

Install it

  1. Copy the downloaded XDJ1KMK2.UPD to the top level of a FAT32 USB stick (the file must keep exactly that name).
  2. Switch the player off, insert the stick, then switch it on while holding LOOP IN and RELOOP/EXIT.
  3. Do not turn the player off or unplug anything during the update.
  4. When it restarts, the version screen shows 2.01.

To go back, run the same steps with Pioneer’s original 1.45 file. Keep that file safe.
